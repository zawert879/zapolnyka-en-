# Примеры конфигураций

Каждая папка — готовый пример уровня, который можно скопировать в `data/N/` и залить.

| Папка | Что демонстрирует |
|---|---|
| `1-sectors/` | Чистые секторы — простейший уровень с несколькими кодами |
| `2-bonuses/` | Бонусы и штрафы — коды, дающие или отнимающие время |
| `3-combo/` | Комбо-типы `секторбонус` и `секторштраф` — код одновременно закрывает сектор и срабатывает бонус/штраф |
| `4-full-level/` | Полноценный уровень — подсказки, автопереход, штрафные подсказки, тело задания, разные типы кодов |

## Как использовать

1. Скопировать папку примера в `data/N/` (где N — номер уровня в en.cx)
2. Подключить `N/conf.json` в `game.json` → массив `levels`
3. Запустить `yarn dev go data/game.json`

## Структура каждого примера

```
N/
├── conf.json    — конфиг уровня (обязательно)
├── codes.json   — коды: секторы, бонусы, штрафы (обязательно)
├── task.html    — тело задания (опционально)
└── README.md    — описание примера
```
