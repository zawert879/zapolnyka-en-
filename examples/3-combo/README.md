# Пример: комбо-типы (секторбонус / секторштраф)

Комбо-коды одновременно закрывают сектор **и** срабатывают как бонус или штраф. Один ввод — два действия.

## Что здесь

- **3 секторбонуса** — при вводе кода закрывается сектор + бонус (−время) + выполняется `help`
- **1 секторштраф** — при вводе закрывается сектор + прибавляется штрафное время

## Когда использовать

- **`секторбонус`** — основные коды уровня, где за каждую находку дают бонусное время. Часто используется с `help` содержащим `<script>` для интерактива (например, отметить находку на карте, открыть карточку).
- **`секторштраф`** — троллинг: игрок нашёл правильный код, но это ловушка. Сектор закрывается, но время прибавляется.

## Разница name vs sectorName

Игрок видит:
- **Имя бонуса** (`name`) — в подсказке `txtHelp` после ввода кода
- **Имя сектора** (`sectorName` или `name` если не задан) — в списке закрытых секторов

Если `name` содержит спойлер ответа — используй отдельный `sectorName`:

```json
{
  "name": "кот (подсказка: мяу)",
  "sectorName": "Сектор 1",
  "type": "секторбонус",
  "answers": ["кот"],
  "time": 60
}
```

## Поля

| Поле | секторбонус | секторштраф |
|---|---|---|
| `name` | Имя бонуса | Имя штрафа |
| `sectorName` | (опц.) отдельное имя сектора | (опц.) отдельное имя сектора |
| `type` | `"секторбонус"` | `"секторштраф"` |
| `answers` | Коды | Коды |
| `time` | Секунды бонуса | Секунды штрафа |
| `help` | (опц.) текст/HTML/script | (опц.) текст/HTML/script |
