# Пример: бонусы и штрафы

Уровень с одним сектором (основной ответ) и дополнительными кодами, которые дают или отнимают время.

## Что здесь

- **1 сектор** — основной код для прохождения уровня
- **2 бонуса** (`тип: бонус`) — дают минус-время за дополнительные находки
- **1 штраф** (`тип: штраф`) — ловушка, прибавляет время

## Когда использовать

- **`бонус`** — награда за дополнительную работу (нашёл доп. объект, решил необязательную загадку). Поле `time` — сколько секунд вычитается.
- **`штраф`** — ловушка, код-приманка. Поле `time` — сколько секунд прибавляется.

## Поля

| Поле | Для бонуса | Для штрафа |
|---|---|---|
| `name` | Название (видно в админке и игроку) | Название |
| `type` | `"бонус"` | `"штраф"` |
| `answers` | Коды | Коды |
| `time` | Секунды бонуса (−время) | Секунды штрафа (+время) |
| `help` | Текст/HTML, показывается после ввода | Текст/HTML |

## Важно

- `time` обязателен для `бонус` и `штраф` (у чистого `сектор` — нет)
- `help` опционален — можно показать текст, картинку или выполнить `<script>`
