# Пример: полноценный уровень

Демонстрирует все возможности conf.json — подсказки, автопереход, штрафные подсказки и разные типы кодов в одном уровне.

## Что здесь

### Коды
- **2 секторбонуса** — находки с бонусом за каждую
- **1 штраф** — код-ловушка (не закрывает сектор, только добавляет время)
- **1 сектор** — финальный ответ уровня

### Конфиг уровня
- **`autopass: 2400`** — автопереход через 40 минут
- **`autopassPenalty: 300`** — штраф за автопереход: +5 минут
- **`hints`** — 2 обычные подсказки (через 10 и 20 минут)
- **`penaltyHints`** — 1 штрафная подсказка (доступна сразу, стоит 3 минуты)
- **`clean: true`** — перед заливкой очистить уровень

## Временные поля — всё в секундах

| Значение | Секунды | Читаемо |
|---|---|---|
| `autopass: 2400` | 2400 | 40 минут |
| `autopassPenalty: 300` | 300 | 5 минут |
| `hints[0].time: 600` | 600 | 10 минут |
| `hints[1].time: 1200` | 1200 | 20 минут |
| `penaltyHints[0].time: 0` | 0 | доступна сразу |
| `penaltyHints[0].penalty: 180` | 180 | штраф 3 минуты |

## Подсказки

### Обычные (`hints`)
Открываются автоматически через указанное время. Игрок видит текст без дополнительных условий.

### Штрафные (`penaltyHints`)
Доступны через указанное время, но для просмотра нужно подтвердить штраф. Поля:
- `time` — через сколько секунд подсказка станет доступна
- `text` — текст подсказки
- `penalty` — штраф в секундах за открытие (опционально)
- `comment` — предупреждение перед открытием (опционально)
