# Пример: чистые секторы

Простейший уровень — игроки ищут коды (секторы) и вводят их. Каждый сектор — одна загадка. Порог можно выставить вручную в админке (например, 2 из 3).

## Что здесь

- **3 сектора** с разными названиями
- У каждого по 1–3 допустимых ответа (синонимы, падежи)
- Без бонусов, штрафов и автоперехода

## Когда использовать тип `сектор`

- Уровень с несколькими независимыми загадками
- Нужен порог прохождения (например, «найди 5 из 7»)
- Не нужно давать/отнимать время за отдельные коды

## Поля

| Поле | Значение |
|---|---|
| `name` | Название сектора (видно игрокам в списке закрытых) |
| `type` | `"сектор"` |
| `answers` | Массив допустимых кодов |
