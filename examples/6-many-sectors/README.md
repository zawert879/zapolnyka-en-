# Пример: много секторов с порогом

Уровень с 5 секторами и порогом прохождения — достаточно закрыть 3 из 5.

## Что здесь

- **5 секторов** — независимые загадки
- **`sectorsToClose: 3`** — порог прохождения (3 из 5)
- Подсказка через 15 минут
- Автопереход 45 минут со штрафом

## Поле `sectorsToClose`

Задаёт сколько секторов нужно закрыть для прохождения уровня. Если не указано — нужны все.

**Важно:** заполняка записывает это поле в админку. Порог можно менять и вручную в LevelEditor.

## Когда использовать

- Уровень-шлакоблокунь (много загадок, нужна часть)
- Полевые уровни, где не все точки могут быть доступны
- Уровни с разной сложностью загадок (лёгкие + сложные, порог мотивирует искать)
