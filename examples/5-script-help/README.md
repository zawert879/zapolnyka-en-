# Пример: скрипт в help (интерактивное задание)

Коды с `<script>` в поле `help` — при вводе кода на странице игрока выполняется JavaScript. Используется для интерактивных заданий: олимпийки, карточки, визуальные эффекты.

## Что здесь

- **4 секторбонуса** с `time: 0` (бонус не даёт времени, но нужен для `help`)
- Каждый `help` содержит `<script>`, который добавляет слово в очередь `window.__q`
- На странице задания `window.__drain()` забирает слова из очереди и показывает их

## Паттерн очереди

```js
// В help бонуса — пушим слово:
<script>(window.__q=window.__q||[]).push('СЛОВО');if(window.__drain)window.__drain();</script>

// В task.html — функция drain забирает и отображает:
window.__drain = function() {
  while (window.__q.length) {
    var word = window.__q.shift();
    // отобразить word
  }
};
```

## Зачем `time: 0`

Тип `секторбонус` требует поле `time`. Ставим `0` — бонус не влияет на время, но `help` выполняется. Это способ привязать скрипт к коду.

## Когда использовать

- Олимпийки (турнирная сетка слов)
- Карточки мемори (открытие карточки по коду)
- Любой интерактив, где введённый код меняет страницу
